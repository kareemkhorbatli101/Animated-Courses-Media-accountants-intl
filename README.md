# Recordings - English for Accountants B1 (International)

The spoken audio for the course at
<https://learnactively.com/accountants-intl/b1>. Generated by
`tools/build-audio.py` in the course project and published here by
`tools/publish-media.py`; nothing here is edited by hand.

It lives apart from the site so that the site's repository carries only
text. Pages fetch these files through jsDelivr, pinned to an exact
commit, so a published page can never silently change what it plays.
